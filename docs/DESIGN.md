# Kanban Studio 设计规范

> 视觉参考：`docs/reference.jpg`（最初的 UI 灵感图）。
> 设计原则：**黑白灰打底，大圆角，胶囊控件，一个强调色只做点缀。** 信息层级靠字号和灰度区分，不靠边框和底色。

---

## 1. 设计变量（Design Tokens）

所有变量都定义在 `styles.css` 顶部的 `.sk-root` 上，深色模式在 `.theme-dark .sk-root` 里覆盖。**组件里只用变量，不写死颜色**（强调色上的文字也走变量）。

### 1.1 颜色

| 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--sk-bg` | `#FFFFFF` | `#131416` | 视图背景 |
| `--sk-panel` | `#F4F4F2` | `#1B1C1F` | 侧栏、列、胶囊控件底 |
| `--sk-panel-2` | `#ECECEA` | `#232428` | 分段控件轨道、"还有 N 张" |
| `--sk-card` | `#FFFFFF` | `#24252A` | 卡片、选中项、计数徽标 |
| `--sk-chip` | `#F3F3F1` | `#2F3036` | 标签胶囊、头像底 |
| `--sk-line` | `#E8E8E5` | `#2E2F34` | 分隔线、树形连接线 |
| `--sk-text` | `#18191B` | `#EDEDEB` | 主文字 |
| `--sk-text-2` | `#4F5257` | `#C2C4C8` | 次级文字 |
| `--sk-text-3` | `#74777C` | `#9B9EA3` | 辅助文字（副标题、计数、占位） |
| `--sk-ink` / `--sk-ink-text` | `#1C1D1F` / `#FFF` | `#EDEDEB` / `#131416` | 主按钮（深色模式反转） |
| `--sk-danger` / `--sk-danger-bg` | `#C9401F` / `#FCE9E3` | `#FF8F75` / 14% 透明 | 紧急、逾期 |
| `--sk-accent` | 由设置决定，默认 `#D7F25C` | 同左 | 强调色 |
| `--sk-accent-ink` | 自动计算 | 同左 | 强调色上的文字（WCAG 亮度对比，黑或白） |

强调色由插件写到 `document.body` 的 `--sk-accent-global` / `--sk-accent-ink-global`，`.sk-root` 和弹窗都从这里读取。

**强调色预设**（`ACCENT_PRESETS`）：青柠 `#D7F25C` · 薄荷 `#9FE3C5` · 天空 `#A9D4FF` · 薰衣草 `#C9B8FF` · 蜜桃 `#FFC2A8` · 琥珀 `#FFD166` · 珊瑚 `#FF7A59` · 靛蓝 `#4F5BD5` · 森林 `#2F7D5B` · 石墨 `#2B2D31`。

**强调色只用在这些地方**：完成标记 ✓、"完成"标签、侧栏选中项的计数、紧凑开关打开时、拖放目标列和拖入图片时的边框、空列插画里的小按钮、弹窗里图片的"封面"角标。不要用在大面积背景、正文文字和主按钮上。

### 1.2 圆角

| 变量 | 值 | 用在 |
|---|---|---|
| `--sk-r-xl` | 24px | 侧栏、列 |
| `--sk-r-lg` | 16px | 卡片、"还有 N 张"、空状态 |
| `--sk-r-md` | 12px | 导航项 |
| 999px | — | 所有胶囊：按钮、标签、开关、分段控件、头像 |
| 10px | — | 卡片封面（= 卡片 16px − 内边距 8px，保证同心） |

### 1.3 阴影

- `--sk-shadow`：静止的卡片和选中项，几乎看不见，只是让白卡片从浅灰底上"浮"出来一点。
- `--sk-shadow-lift`：卡片悬停、浮起元素。
- 深色模式下阴影换成 1px 浅色描边。

### 1.4 字体与字号

- 字体：`var(--font-interface)`，跟随 Obsidian 界面字体，回退到 PingFang SC / Microsoft YaHei。
- **所有字号都写成 `calc(Npx * var(--sk-fs, 1))`**，以便三档缩放：小 `0.9`、中 `1`、大 `1.14`（`.sk-size-s/m/l`）。新加的文字也要遵守这个写法。例外：「小 / 中 / 大」按钮本身（故意固定字号，用来示意大小）、缩略图上的计数角标（10px），以及插件根容器外的弹窗和大图预览。
- 基准字号（中档）：

| 元素 | 字号 / 字重 |
|---|---|
| 看板标题 h1 | 40px / 600，字距 −0.035em |
| 卡片标题、列标题 | 16px / 500 |
| 统计行 | 15px |
| 正文、导航、按钮 | 13.5–14.5px |
| 副标题、标签胶囊 | 12.5–13px |
| 计数徽标 | 11.5–12px |

### 1.5 间距

- 视图外边距 16px；侧栏和主区之间 20px。
- 列宽 292px，列间距 14px，列内边距 14/12px。
- 卡片间距 10px，卡片内边距 14/16px。
- 控件高度：主按钮和胶囊 48px，图标按钮 40px，导航项 40px，标签胶囊 28px（紧凑模式 24px）。可点区域不小于 40px。

## 2. 布局

```
┌ .sk-root ───────────────────────────────────────────────────────────┐
│ ┌ .sk-side 264px ┐ ┌ .sk-main ─────────────────────────────────────┐ │
│ │ (⇤)        (+) │ │ ([⇥] 侧栏隐藏时才有) 看板标题 h1  [显示][紧凑][小中大] │ │
│ │ [全部|进行中]  │ │                                                │ │
│ │ (搜索)         │ │ 统计行                     [▦|☰] [+ 新建卡片]  │ │
│ │ 全部卡片  11   │ │ 成员头像 · N 位成员                             │ │
│ │ 视图 ▾         │ │ ┌ 列 ┐ ┌ 列 ┐ ┌ 列 ┐ ┌ 列 ┐ [+ 添加列]  → 横向滚动 │ │
│ │ ├ 高优先级     │ │ │卡片│ │    │ │    │ │空状态│                    │ │
│ │ 标签 ▾ / 成员 ▾│ │ └────┘ └────┘ └────┘ └────┘                    │ │
│ │ ── 已完成 / 源文件 │                                               │ │
│ └────────────────┘ └──────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

- 侧栏可隐藏：`.sk-side-hidden` 把宽度、内边距收到 0，0.28s 过渡，主区自动占满。
- 窄屏（≤760px）：上下堆叠，列宽 84vw。
- 每列只在自己内部纵向滚动，整个看板横向滚动。

## 3. 组件

### 3.1 卡片 `.sk-card`
从上到下：
1. **封面图**（可选，"顶部大图"模式）：高度 120 / 168 / 240px；四周留 8px（负 margin 抵消内边距），圆角 10px，1px 内描边；加载完成后淡入 0.35s；悬停放大 1.035；多图时右下角显示毛玻璃计数角标；加载失败显示 `image-off` 图标，高度 64px。
2. **标签行**：优先级（4 格信号条 + 文字，紧急为红色）、日期（日历图标；逾期为红色；今天/明天/昨天/M月D日）、完成。
3. **标题**：16px / 500。
4. **副标题**：描述第一行 · #标签，灰色。
5. **底栏**：头像 + 负责人 …… 金额（等宽数字）。
- "右侧缩略图"模式：标题区右边放 64px 方图（紧凑模式 44px）。
- 状态：悬停上浮 1px 并加大阴影；拖动中半透明并缩到 0.98；完成后标题变灰并加删除线；有图片文件拖到卡片上时显示强调色边框。
- 每个字段都可以在设置里隐藏（见 §5）。

### 3.2 列 `.sk-col`
- 头部：列名、数量徽标、完成列标记（强调色圆 ✓）、排序标记（设了排序才出现，点一下正序 / 倒序互换）、"…"菜单。
- 排序（"…"菜单）：手动 / 按日期从早到晚 / 按日期从晚到早。只影响显示，没有日期的卡片排最后；设置存在看板文件里，每列一份。
- 折叠（默认"放不下才折叠"）：卡片超出这一列的可见高度时，只显示放得下的几张，其余折叠为"还有 N 张"；展开后如果仍然超出，底部显示"收起"；否则显示"+ 添加卡片"。也可以在设置里改成固定张数或不折叠。
- 有筛选条件时不折叠。新建 / 移过来的卡片所在的列会自动展开并滚到那张卡。
- 空列显示空状态：插画（窗口 + 三个色块 + 强调色"+"胶囊 + 倾斜小卡片）、标题、说明、主按钮。

### 3.3 侧栏
- 顶部：左边收起侧栏按钮（`panel-left-close`），右边"+"新建卡片。不再显示看板标题（和主区大标题重复，侧栏窄时还会被截断）。侧栏隐藏后，看板标题左边出现展开按钮（`panel-left-open`），侧栏显示时这个按钮不出现。主区不再显示"文件夹 › 当前筛选"路径（和 Obsidian 自带的标题栏重复）。
- 分段控件：全部 / 进行中。
- 搜索框：胶囊形，右边有 `/` 提示（**快捷键还没接上**）。
- 导航项：图标 + 文字 + 计数；选中项白底加阴影，计数用强调色。
- 分组（视图 / 标签 / 成员）可折叠，子项用圆角 L 形树线连接。
- 底部：已完成、Markdown 源文件、设置（打开本插件设置页）。

### 3.3.1 看板标题
- h1 本身可编辑（`contenteditable="plaintext-only"`），和 Obsidian 的行内标题一样，不是按钮。
- 悬停 / 编辑时显示 `--sk-panel` 底色，编辑时加 1px `--sk-line` 描边；左右 8px 内边距用负 margin 抵消，文字不移位。

### 3.4 顶部工具栏
显示（眼睛图标，弹出可勾选菜单）· 紧凑开关 · 小/中/大 · 看板/列表 · 主按钮"新建卡片"。

### 3.5 弹窗
- 卡片编辑：标题（回车保存）、列（放在第二项，新建时一眼看到放进哪一列）、描述、图片区、优先级、日期、负责人、金额、标签，底部 删除 / 取消 / 保存。被隐藏的字段不出现在弹窗里。
- 图片区：网格，每张 4:3；第一张有"封面"角标和描边；鼠标悬停显示"设为封面"和"移除"；最后两格是虚线的"上传图片"和"从库中选择"；支持拖入和粘贴。
- 图片大图预览：背景 86% 深色遮罩，图片按比例完整显示，底栏显示文件名、第几张、上一张/下一张；方向键切换。

## 4. 动效

| 场景 | 时长 | 说明 |
|---|---|---|
| 按钮 / 颜色变化 | 0.15s ease | |
| 卡片悬停上浮 | 0.15s | translateY(−1px) |
| 侧栏收起 | 0.28s ease | flex-basis、内边距、透明度 |
| 图片淡入 | 0.35s | |
| 封面悬停放大 | 0.45s cubic-bezier(.2,.7,.2,1) | |
| "+"圆按钮悬停 | — | 旋转 90° |
| 新建 / 换列的卡片 | 0.24s | 只有这张卡浮现：从下方 6px、98% 大小淡入 |
| 删除卡片 | 0.2s | 这张卡收起（高度、透明度），下面的卡片自然补位 |
| 重绘（任何改动后） | — | 不做整体动画：保持各列和侧栏的滚动位置，加载过的图片直接显示不再淡入 |
| 分段按钮切换（全部/进行中、小/中/大、看板/列表） | 约 0.35s | 白色滑块用弹簧滑到新选项（刚度 420、阻尼 30，轻微回弹），文字颜色按覆盖程度渐变；可按住拖动，松手吸附，带一点惯性。"减少动态效果"时直接到位 |

## 6. 无障碍

- 所有可点的东西都是真正的 `<button>` / `<input>`，纯图标按钮都有 `aria-label`。
- 卡片可以用 Tab 选中，按回车打开。
- 文字对比度：`--sk-text-3`（#74777C）在白底上是 4.49:1，差一点没到 WCAG AA 的 4.5:1，**建议实现时调深到 `#6F7277`**。
- 已知问题：深色模式 + "石墨"强调色时，强调色和卡片底色太接近，几乎看不见。
